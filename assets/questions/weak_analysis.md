# 薄弱环节分析

## 分析维度

### 1. 章节正确率
优先根据完整作答记录统计各章正确率，识别薄弱章节。

正确率计算：`正确率 = (该章已作答题数 - 该章答错题数) / 该章已作答题数 × 100%`

如果当前只有 `archive.json` 的错题记录，没有完整作答记录，不要把未作答题目默认算作答对。此时改用错题数量、错误次数、最近复习时间和章节权重估算复习优先级。

### 2. 错题类型分析
- **概念混淆题**：对相似概念区分不清
- **记忆遗漏题**：知识点未记住
- **理解偏差题**：理解了但应用错误
- **计算错误题**：公式或计算过程出错

### 3. 复习优先级
根据以下因素确定复习优先级：
- 有完整作答记录时，正确率越低 → 优先级越高
- 只有错题记录时，错题数量越多 → 优先级越高
- 错题次数越多 → 优先级越高
- 距离上次复习时间越长 → 优先级越高
- 能力篇（18-23章）权重 ×1.5（案例和论文重点）

## 复习建议规则

| 正确率 | 建议 |
|--------|------|
| < 60% | 立即重新学习该章教材，做全部练习题 |
| 60-70% | 重点复习错题对应知识点，重做错题 |
| 70-80% | 回顾错题，做模拟题巩固 |
| 80-90% | 定期复习错题，保持记忆 |
| > 90% | 该章掌握良好，可适当减少复习频率 |

## 使用方式

用户可以询问：
- "我的薄弱环节是什么？"
- "哪些章节需要重点复习？"
- "分析一下我的错题情况"
- "今天应该复习什么？"

Skill 会读取 archive.json 中的错题记录，进行分析并给出个性化建议。
